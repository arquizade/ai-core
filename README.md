# ai-core

Shared memory for every AI model you use. Open this folder as an Obsidian vault.

## Backup
Run git init in this folder. Commit after each working session.
Sync the folder with a private repository or a sync service. Never sync it to a public location.

## Config files
- CLAUDE.md: Claude Code
- AGENTS.md: Codex and other agents
- GEMINI.md: Gemini CLI

All three files hold the same rules. Edit them together.
